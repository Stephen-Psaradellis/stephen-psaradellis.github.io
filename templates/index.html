Free local business website templates

Seven one-page website templates for local service businesses. Plain HTML and CSS with a little JavaScript: no framework, no build step, no tracking. Each one is MIT licensed, so you can use it for your own business or for a client and change anything.

Every template has: a phone number people can tap on a phone, a click-to-call header, a working dark mode, an accessible menu with a skip link, schema.org markup for the business type, and a contact section with your phone and email.

How to use one

  • Download the repository (GitHub's green Code button, then Download ZIP) or fork it.
  • Change the business name, phone number, address and services in index.html. The README lists every line to edit.
  • Host it free on GitHub Pages, Netlify or Cloudflare Pages, or upload the folder to any web host.
